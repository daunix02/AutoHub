# -Linux Server Health Reporter

## Project Overview

The Linux Server Health Reporter is a Bash-based utility designed to collect basic Linux server information and generate a structured health report.

The project simulates a basic operational task performed by DevOps and Linux system administrators.

------ DAY 9 -------
### Linux Process Management – Day 4

- Practised foreground and background processes.
- Used `&` to run processes in the background.
- Used `jobs` to list background jobs.
- Used `fg` to bring jobs to the foreground.
- Used `Ctrl + Z` to suspend processes.
- Used `bg` to resume suspended processes in the background.
- Verified that moving a process between foreground and background does not change its PID.

**Key Learning:** Foreground and background execution changes job control, not the process identity.
